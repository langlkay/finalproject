# finalproject
Flask web app that allows users to add art works with descriptions building a digital portfolio

Initially, my MVP only includes allow users to add and save their art to this site with a small description. Soon, the goal would be for users to be able to click on individual works and view types of information involving that work such as reference images, text information, and sketches. In the far future, making this site something one could log into would be great, creating an easy platform for artists to organize their works in.
